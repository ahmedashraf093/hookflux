# Introduction

HookFlux is a robust, self-hosted solution for automating deployments via GitHub webhooks. It replaces complex CI/CD pipelines with simple, reusable Bash scripts and provides a beautiful real-time dashboard.

## Why HookFlux?

- **Simplicity**: Just write Bash scripts. No complex YAML flows to learn.
- **Visibility**: See exactly what's happening on your server in real-time.
- **Control**: You own the infrastructure. No third-party limits.
